# Online Shop Template
A polished, responsive online shop template — ready to rebrand and resell.
## Features
- Product grid with category filters and live search
- Add-to-bag cart with slide-in drawer
- Copyable order summary (demo checkout, no backend)
- Light/dark themes, mobile-friendly layout
- Single self-contained index.html, no build step
## Customize
Replace the sample products, prices, store name, and images in index.html. Connect real payments and inventory before launching.
## Preview
Open index.html in a browser, or enable GitHub Pages (Settings > Pages > Deploy from branch > main).
